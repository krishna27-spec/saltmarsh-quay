# Saltmarsh Quay

An interactive low-poly 3D harbour diorama built with [Three.js](https://threejs.org/), in a single HTML file.

A block of land and sea cut away at the sides to show soil layers and water depth, with a small town, two quay cranes, a container ship, drifting boats and a lighthouse on the breakwater.

- Drag to orbit, scroll to zoom
- Time of day: dawn, noon, dusk (lighthouse beam and window lights come on at dusk)
- Wave strength and sea fog sliders
- Animated water with ripples and seabed caustics
- Every model is built from primitives in code; no image or model files

Live site: https://krishna27-spec.github.io/saltmarsh-quay/
